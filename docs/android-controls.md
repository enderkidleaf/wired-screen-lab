# Android 接收端界面 0.3.0

- 半透明圆角控制面板，连接提示与技术统计分开显示。
- 点击“隐藏面板”收起状态信息；右上角“控制”恢复面板。
- 隐藏状态与保持亮屏设置保存在 App 内，重开后保留。
- “详细信息”展开帧率、解码器和低延迟模式；面板可滚动，便于小屏和大字体使用。
- “保持亮屏”默认开启；关闭后按系统超时息屏，息屏可能暂停连接。
- 断开时清除旧统计。视频协议、编码和解码参数未调整。
